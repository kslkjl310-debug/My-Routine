# My Tools

루틴, 신앙관리(성경 읽기 체크), 역량관리(플래너·OPIc), 재정관리(가계부)를 한곳에서 쓰는 앱이에요.
폰 홈 화면에 설치해서 앱처럼 쓰고, Google 로그인으로 폰과 PC가 같은 데이터를 써요. 오프라인에서도 열려요.

파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 왼쪽 영역 메뉴, 하단 탭, 로그인 화면. 도구들을 한 화면에 담아요 |
| `routine.html` `bible.html` `reading.html` `planner.html` `opic.html` `budget.html` | 각 도구 |
| `backend.js` | 저장소. 로그인하면 Firebase에, 아니면 이 기기에 저장해요 |
| `firebase-config.js` | **내가 채울 파일.** Firebase 설정값을 넣어요 |
| `firestore.rules` | 데이터 보호 규칙. Firebase에 붙여 넣어요 |
| `manifest.webmanifest` `sw.js` `icons/` | 앱 설치와 오프라인 사용 |

## 1. Firebase 프로젝트 만들기 (무료, 한 번만)

1. <https://console.firebase.google.com> 에 Google 계정으로 들어가 **프로젝트 추가**를 눌러요. 이름은 아무거나 괜찮아요. Google 애널리틱스는 꺼도 돼요.
2. 왼쪽 **빌드 → Authentication → 시작하기 → Google**을 켜고, 지원 이메일을 고른 뒤 저장해요.
3. **빌드 → Firestore Database → 데이터베이스 만들기**. 위치는 `asia-northeast3 (서울)`, 모드는 **프로덕션 모드**로 해요.
4. Firestore의 **규칙** 탭을 열고, 안에 있는 내용을 지운 뒤 `firestore.rules` 파일 내용을 붙여 넣어요. 붙여 넣기 전에 파일 안의 `'내이메일@gmail.com'`과 `'배우자이메일@gmail.com'`을 두 사람이 실제로 로그인에 쓰는 Google 이메일로 바꾸고 **게시**해요. 이 두 계정만 우리집 가계부를 함께 쓸 수 있어요.
5. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹 앱(`</>`)**을 추가해요. 호스팅은 체크하지 않아도 돼요. 화면에 나오는 `firebaseConfig` 값 6개를 `firebase-config.js`에 그대로 붙여 넣어요.
6. **Authentication → 설정 → 승인된 도메인**에 `내아이디.github.io`를 추가해요. 이걸 빼먹으면 로그인할 때 "승인된 도메인" 오류가 나요.

## 2. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들어요. 이름은 예를 들어 `my-tools`로 하고, 공개(Public)로 해요. 무료 계정의 Pages는 공개 저장소에서 써요. 코드에는 비밀번호가 없고, 데이터는 로그인한 본인만 읽도록 규칙이 막아 줘요.
2. 이 폴더 안의 **모든 파일**(`.nojekyll`, `icons` 폴더 포함)을 저장소에 올려요. 저장소 화면의 **Add file → Upload files**에 끌어다 놓으면 돼요.
3. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/my-tools/` 에서 열려요.

## 3. 폰에 설치

- **안드로이드(Chrome)**: 위 주소를 열고 로그인한 뒤, 오른쪽 위 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**. 화면 위쪽에 "앱으로 설치" 버튼이 뜨면 그걸 눌러도 돼요.
- **아이폰(Safari)**: 주소를 열고 공유 버튼 → **홈 화면에 추가**.

## 앱을 고쳐서 다시 올릴 때

파일을 같은 이름으로 다시 올리면 돼요. 앱은 열 때마다 새 파일을 먼저 확인하고, 인터넷이 안 되면 저장해 둔 파일로 열려요.

## 알아 둘 점

- `firebase-config.js`를 비워 두면 로그인 없이 **그 기기에만** 저장하는 모드로 쓸 수 있어요. 폰과 PC의 데이터는 합쳐지지 않아요.
- 저장된 데이터는 Firestore의 `data/users/<내 uid>/` 아래에만 있고, 본인 계정만 읽고 쓸 수 있어요.
- OPIc 스피킹 트레이너의 **AI 음성**: 음성 설정에서 켜면 기기 안에서 도는 신경망 음성 모델(Kokoro-82M, 약 90MB)로 영어를 읽어요. 처음 한 번 내려받고, 만든 문장은 기기에 저장돼요. 켜 두면 보고 있는 질문의 소리를 미리 만들어 둬요. 인터넷이 느리거나 폰이 느리면 끄고 기본 음성을 쓰면 돼요.
- OPIc 스피킹 트레이너의 Claude 연동 기능(AI 첨삭 등)은 아티팩트 안에서만 동작해서, 이 앱에서는 꺼져 있어요.
- **우리집 가계부는 두 사람이 함께 써요.** 배우자도 같은 주소를 열어 **자기 Google 계정**으로 로그인하면 같은 장부가 보이고, 한쪽이 적으면 다른 쪽에 바로 나타나요. 규칙에 적은 두 이메일 외의 계정은 가계부를 읽거나 쓸 수 없어요. 루틴·성경·독서·플래너·OPIc는 각자 따로 저장돼요.
- 예전 아티팩트 허브에 있던 데이터는 자동으로 옮겨지지 않아요. 각 도구의 **내보내기**로 파일을 저장한 뒤 이 앱에서 **불러오기**를 하면 돼요.
